## 固件声明

[`manifest.json`](manifest.json) 列出各型号的固件 BIN 和双语说明，路径均相对于仓库根目录。新增固件版本时，将 BIN 路径加入对应型号的列表，并更新该型号的两份 README。需要在固件中心继续提供的版本须保留在列表中。
